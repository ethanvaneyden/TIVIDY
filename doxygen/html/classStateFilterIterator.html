Detailed Description

Walks the tree depth-first and yields only items whose state name matches.

Reuses DepthFirstIterator for the walk and adds a skip loop on top, so the traversal code is not duplicated. The state is chosen at construction, so one class covers every item state, for example "Available" (to find work to assign) or "Rejected" (the operator's review queue).

Containers and the root inherit the default Component::getStateName(), which returns an empty string, so only items can ever match.

StateFilterIterator rejected(root, "Rejected");
for (rejected.first(); !rejected.isDone(); rejected.next())
review(rejected.current());
