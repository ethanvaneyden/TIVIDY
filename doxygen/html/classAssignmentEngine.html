Detailed Description

Strategy Context: holds the active AssignmentStrategy and delegates to it.

The engine never knows which concrete strategy it holds. It only CHOOSES a worker; it never changes the item. The AssignItem command takes the returned worker and calls Item::assign(), which does the state change and pending count.

The strategy is chosen from outside: by the scenario's factory at construction, or at runtime through setStrategy().
