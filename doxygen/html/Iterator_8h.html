Detailed Description

Abstract external iterator for traversing the work composite tree.

Part of the Iterator pattern. The client owns the loop and drives the traversal with first(), next(), isDone() and current(), so the traversal logic is kept out of Component, Container and Item.

Iterator *it = root->createIterator();
for (it->first(); !it->isDone(); it->next())
use(it->current());
delete it;
