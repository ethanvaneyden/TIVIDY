Detailed Description

Single API surface for the REST layer.

All workflow logic lives behind this facade. The REST handlers call methods here; no REST handler touches the engine directly.

This top-level facade is a thin router. It owns the scenario-specific facades and delegates all calls to the appropriate one based on the instance ID. This respects SRP and OCP.
