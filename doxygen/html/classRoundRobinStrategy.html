Detailed Description

Concrete Strategy: takes turns, cycling through the pool in order.

Stateful: remembers the last worker chosen and picks the one after it, wrapping to the start. The last pick is stored as a pointer rather than an index, so it stays correct if the pool changes between calls. If the last pick is no longer in the pool, the cycle restarts from the first worker.
