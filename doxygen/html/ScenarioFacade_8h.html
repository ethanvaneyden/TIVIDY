Detailed Description

Abstract base for per-scenario facades.

Each scenario (education, healthcare, and any future scenario) exposes the same operations through this interface. The top-level TividyWorkflow facade delegates to the appropriate ScenarioFacade based on the instance ID.

This satisfies the Open/Closed Principle: adding a new scenario means writing a new subclass, with no changes to TividyWorkflow or the REST layer.
