Detailed Description

A leaf workflow component with an execution and review lifecycle.

This class acts as the Context in the State pattern and the Leaf in the Composite pattern.

It owns its lifecycle state (via std::unique_ptr) but does NOT own its assignee or reviewer. The ParticipantRegistry must outlive this item.

Operations like start() and complete() delegate to the current ItemState. If an operation is invalid for the current state, the state class will throw a std::logic_error.
