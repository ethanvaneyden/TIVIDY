Detailed Description

Visits a node and its descendants in depth-first order.

For the tree Root -> (C1 -> A, B), (C2 -> C) the visiting order is Root, C1, A, B, C2, C. next() goes down to the first child if there is one, otherwise across to the next sibling, otherwise up through getParent() until an ancestor has a next sibling. The climb stops at the starting node, so an iterator started on a Container never leaves that subtree.

Note
Relies on leaves returning an empty vector from getChildren().
